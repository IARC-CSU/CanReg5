# 9. Known Issues

## Known bugs (errors)

- <div class="flushleft">

  Using a population dataset with a cut off age at less than 85 while
  building some R-tables leads to errors in the last age group in the
  tables.

  </div>

  - <div class="flushleft">

    Severity: Shouldn’t cause loss of data

    </div>

  - <div class="flushleft">

    Priority: Medium

    </div>

  - <div class="flushleft">

    Category: Tables

    </div>

## Known limitations

- <div class="flushleft">

  You need a population dataset with 5 years age groups for many of the
  tables to work properly…

  </div>

- <div class="flushleft">

  Age can not yet be calculated automatically.

  </div>

- <div class="flushleft">

  The result set in the browser is sometimes very slow to scroll around
  in.

  </div>

  - <div class="flushleft">

    Solution: Use filters to minimize the number of records shown at any
    time or only browse the “Patient” or the “Tumour” table.

    </div>

  - <div class="flushleft">

    Severity: Shouldn’t cause loss of data

    </div>

  - <div class="flushleft">

    Priority: Low

    </div>

  - <div class="flushleft">

    Category: Database/Browse

    </div>

  </div>
